# 文档校验与撤销重做

## 1. 文档校验

`DocumentValidator` 在几何构建前执行，当前检查参数名称、重复名称、命令注册、必填字段和输出引用。校验错误不应交给 OCCT 处理，避免无效输入进入原生层。

## 2. 撤销重做

所有文档修改使用 `IDocumentAction`。`DocumentHistory` 保存撤销栈和重做栈，并支持事务组合。参数连续输入通过 `TryMerge` 合并，避免每个字符生成一条历史记录。

## 3. 事务

创建一个完整命令时，可将添加命令、设置字段和设置变换放入同一事务。事务释放时提交为一条撤销记录。

## 4. 下一步

后续增加命令操作、字段操作、引用保护、删除恢复和构建缓存失效通知。
