# Bridge 2.7 source API additions

This page records source-verified 2.7 additions while the complete generated API reference awaits a Windows regeneration.

## STEP assembly model

New public types:

```csharp
public enum OcctAssemblyNodeKind { Assembly = 0, Instance = 1, Part = 2 }

public readonly record struct OcctAssemblyColor(double R, double G, double B, double A = 1.0);
public readonly record struct OcctAssemblyTransform3d(/* 12 affine components */);
public readonly record struct OcctAssemblyStyle(
    bool Visible,
    OcctAssemblyColor? SurfaceColor,
    OcctAssemblyColor? CurveColor);
public readonly record struct OcctAssemblySubshapeStyle(
    OcctShapeType ShapeType,
    int SubshapeIndex,
    OcctAssemblyStyle Style);

public sealed class OcctAssemblyNode;
public sealed class OcctAssemblyDocument;
```

`OcctAssemblyNode` exposes stable ID/index/parent information, `Kind`, `Name`, `ReferenceName`, optional `Shape`, style, local/global transforms, subshape styles, `Parent` and `Children`.

`OcctAssemblyDocument` exposes `SourcePath`, `PrimaryShape`, `Nodes`, `Roots`, `Assemblies`, `Instances` and `Parts`.

New `OcctEngine` entry point:

```csharp
public OcctAssemblyDocument ImportStepDocument(string filePath);
```

It performs normal STEP import, reads the XDE assembly snapshot and projects the occurrence tree into managed objects. Existing `ImportStep()` remains available.

## First-class point presentation

`OcctObjectKind` adds `Point = 5`.

```csharp
public enum OcctPointMarker
{
    Point = 0, Plus = 1, Star = 2, X = 3,
    Circle = 4, CirclePoint = 5, CirclePlus = 6,
    CircleStar = 7, CircleX = 8,
    Ring1 = 9, Ring2 = 10, Ring3 = 11, Ball = 12
}

public sealed class OcctPoint : OcctObject;
```

New `OcctEngine` methods:

```csharp
public OcctPoint AddPoint(
    OcctPoint3d position,
    OcctPointMarker marker = OcctPointMarker.CirclePoint,
    double scale = 3.0,
    System.Drawing.Color? color = null);

public void SetPointPosition(OcctPoint point, OcctPoint3d position);
public void SetPointStyle(
    OcctPoint point,
    OcctPointMarker marker,
    double scale,
    System.Drawing.Color color);
```

The Native implementation uses real `AIS_Point + Geom_CartesianPoint` presentation rather than a BRep vertex workaround.

## Surface-only resize

New `OcctEngine` method:

```csharp
public void ResizeSurface();
```

It synchronizes the OCCT render surface with the native window size without drawing a frame, allowing UI adapters to coalesce resize events and issue one later `Redraw()`.

## Contract

These additions are part of source **Bridge 2.7.0 / ABI 4**. The currently tracked Binary SDK is still 2.6.0; Binary consumers receive these APIs only after the 2.7 Windows publish.
