# OcctAssemblyNode

- **程序集:** `OcctNet.dll`
- **命名空间:** `OcctNet`

## 声明

```csharp
public sealed class OcctAssemblyNode
```

## 说明

One node of the imported XDE occurrence tree. OcctNet.OcctAssemblyNode.Id is the stable XDE assembly-item path generated by OCCT and does not depend on display names.
