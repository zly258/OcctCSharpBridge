# OcctScript 编辑器第一阶段

## 已实现范围

- WPF 主窗口与 OCCT 三维视图。
- 新建、打开、保存 `.ocsproj` 文档。
- 参数列表及表达式编辑。
- Box、Cylinder 命令创建与删除。
- 命令字段、位置、旋转和缩放编辑。
- 参数与命令字段的撤销、重做。
- 参数计算、真实 OCCT 几何构建及 AIS 显示。
- 命令列表与三维视图双向选择。
- 轴测、正视、俯视和适合窗口。
- 构建错误与状态消息。

## 当前边界

第一阶段采用轻量代码后置完成可运行闭环，未引入第三方 MVVM 框架。后续将把文档会话、选择、属性编辑器和命令操作迁移到 `OcctScript.Presentation`，主窗口只保留视图职责。

当前变换和命令名称编辑已可工作，但尚未全部纳入撤销栈；参数重命名、引用自动更新、增量缓存、布尔命令和多文档标签页将在后续阶段实现。

## 运行方式

1. 使用 x64 配置编译原生 `OcctNative`。
2. 编译 `OcctBridge.sln`。
3. 将 OCCT 运行库与 `OcctNative.dll` 放置到编辑器输出目录或由现有构建脚本完成复制。
4. 启动 `OcctScript.Editor`。
