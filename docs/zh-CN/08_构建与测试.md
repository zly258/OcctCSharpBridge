# 构建与测试

`avalonia` 分支使用 Windows/Linux 两套平台构建入口，共享同一份源码/API Contract。该分支不跟踪 `dist`，也不维护分支内 Binary SDK 发布流程。

## Windows

```powershell
.\build.ps1 validate Release
.\build.ps1 managed Release
.\build.ps1 test Release
.\build.ps1 smoke Release -OcctRoot "D:\tools\occt-vc144-64"
.\build.ps1 avalonia-smoke Release -OcctRoot "D:\tools\occt-vc144-64"
.\build.ps1 docs Release
```

推荐完整非 GUI 验证：

```powershell
.\build.ps1 all Release -OcctRoot "D:\tools\occt-vc144-64"
```

`all` 统一执行 Native + Managed + ManagedTests + Headless Smoke。`avalonia-smoke` 单独验证真实 Avalonia Desktop → `OcctAvaloniaViewport` → Native Surface → OCCT Viewer 链路。

## Linux

```bash
./build.sh validate
./build.sh managed Release
./build.sh test Release
./build.sh smoke Release
./build.sh avalonia-smoke Release
./build.sh docs Release
```

推荐完整非 GUI 验证：

```bash
./build.sh all Release
```

`all` 同样执行 Native + Managed + ManagedTests + Headless Smoke。`avalonia-smoke` 需要 X11/XWayland 桌面会话，用于验证完整 Avalonia Viewer 链路。

Linux Native 输出按 CMake Configuration 目录生成，例如：

```text
build/native/bin/Release/libOcctNative.so
```

该分支不包含 sync、WinForms/WPF、跟踪式 Binary SDK、分支内发布脚本、NuGet 发布链或 GitHub Actions。
