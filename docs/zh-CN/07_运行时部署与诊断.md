# 运行时部署与诊断

`main` 仅支持 Windows x64。

Native Bridge：

```text
OcctNative.dll
```

默认开发环境 OCCT 路径：

```text
D:\tools\occt-vc144-64\inc
D:\tools\occt-vc144-64\win64\vc14\lib
D:\tools\occt-vc144-64\win64\vc14\bin
```

`OcctRuntime` 负责解析配置的 Native Bridge/OCCT Runtime，并在 DLL 无法加载时提供诊断信息。

`dist/win-x64` 是 Bridge Binary SDK，不等于完整应用 Runtime Closure。实际应用仍需按自身发布策略和第三方许可证部署 OCCT/相关运行库。

Linux Runtime 属于 `avalonia` 分支：Native Bridge 为 `libOcctNative.so`，默认 OCCT Library 路径 `/usr/local/lib`。
