# 08 构建测试与发布

`build.ps1` 是 `main` 的统一本地入口。验证分为：**仓库静态契约 → Managed Regression → 真实 Native Smoke → 双语 API Reference → Binary SDK**。`publish.ps1` 负责把公开 API 文档、正式 Binary SDK 和 demo 同步串成一个完整发布事务。

## 1. 当前基础契约

`bridge-contract.json` 是版本、平台和 API 数量的机器可读事实源。当前基线：Bridge `2.6.0`、Native ABI `4`、OCCT `7.9.0`、Native/PInvoke `344/344`、Viewer/Modeling `210/134`、.NET SDK `10.0.302`、`net10.0-windows`、C# `14.0`。

## 2. build target

```powershell
.\build.ps1 validate Release
```
执行长期仓库静态契约，不需要 OCCT SDK。

```powershell
.\build.ps1 managed Release
```
增量构建 `OcctNet` 与三个 UI Host。

```powershell
.\build.ps1 test Release
```
使用 .NET 10 Microsoft Testing Platform 执行 Managed Regression，不加载 OCCT Native Runtime。

```powershell
.\build.ps1 native Release
```
使用 CMake + MSVC + OCCT 7.9.0 构建 `OcctNative.dll`。

```powershell
.\build.ps1 smoke Release -OcctRoot "D:\tools\occt-vc144-64"
```
构建真实 Native Bridge 并执行 Native Smoke。Smoke 输出目录只放当前 `OcctNative.dll`，依赖由 `OcctRuntime` 根据 `OCCT_ROOT` 配置搜索路径。

```powershell
.\build.ps1 pack Release
```
生成并校验四个 Managed NuGet/Symbol Package；Managed 包不包含 OCCT Runtime 或 `OcctNative.dll`。

```powershell
.\build.ps1 docs Release
```
构建 Managed SDK 后运行 `tools/OcctApiDocsGenerator`，生成完整中英文公开 API Reference：

```text
docs/zh-CN/api/reference/**
docs/en-US/api/reference/**
```

每个公开类型独立一页，覆盖程序集、命名空间、声明、构造函数、属性、事件、方法、参数、返回类型、字段/枚举值和 XML Documentation。

```powershell
.\build.ps1 all Release
```
构建 Native + 四个 Managed SDK 项目，不隐式执行 test/smoke。

```powershell
.\build.ps1 clean Release
```
清理 `build/`、`artifacts/`、项目 `bin/obj` 和 API Docs Generator 的 `bin/obj`；不删除已提交的 `dist/`。

## 3. Binary SDK：`build.ps1 dist`

正式二进制只允许 Release：

```powershell
.\build.ps1 dist Release -OcctRoot "D:\tools\occt-vc144-64"
```

要求 Git 工作区干净，并按顺序完成：

```text
Native build
→ Managed build
→ Managed tests
→ Native smoke
→ 收集 Binary SDK
→ SHA-256
→ bridge-manifest.json
→ staging
→ 原子替换 dist/win-x64
```

生成：

```text
dist/win-x64/
├─ OcctNative.dll
├─ OcctNet.dll
├─ OcctNet.WinForms.dll
├─ OcctNet.Wpf.dll
├─ OcctNet.Avalonia.dll
├─ bridge-contract.json
└─ bridge-manifest.json
```

Manifest 记录 Bridge Version、Native ABI、OCCT Version、Target Framework、SDK/Language Version、Release Configuration、源码 Commit 和所有分发文件 SHA-256。

替换正式 `dist` 前先写 staging；上一版存在时先移动到 backup。替换异常会恢复上一版，避免发布失败后留下半套 DLL。

`dist` 是 Thin Binary SDK，不包含 OCCT `TK*.dll` 和第三方 Runtime。

## 4. 正式发布：`publish.ps1`

```powershell
.\publish.ps1 -OcctRoot "D:\tools\occt-vc144-64"
```

发布要求 `main` 工作区开始时完全干净。脚本执行：

```text
build.ps1 docs Release
→ 生成完整 zh-CN/en-US API Reference
→ API Reference 有变化则 commit
→ 再次确认工作区干净
→ build.ps1 dist Release
→ Release Build + Managed Test + Native Smoke
→ 生成/校验 Binary SDK
→ commit dist/win-x64
→ push main
→ fetch demo
→ 临时 detached worktree
→ 只同步 demo/dist/win-x64
→ 校验 Contract / Manifest / SHA-256
→ commit + push demo
→ 删除临时 worktree
```

这个顺序保证 `bridge-manifest.json.sourceCommit` 精确对应生成 DLL 的源码和已提交公开 API 文档。脚本不会切换当前开发目录分支，也不使用 GitHub Actions。

## 5. 静态契约

当前只保留长期仓库不变量检查：

- `check-version-contract.ps1`；
- `check-architecture-boundaries.ps1`；
- `check-bulk-abi.ps1`；
- `check-native-build-structure.ps1`；
- `check-api-surface.ps1`；
- `check-sdk-package.ps1`。

README 标题、方法必须位于某个 partial、实现必须逐字包含某段代码等不再作为静态 Contract。行为由编译、测试和 Smoke 验证。

## 6. Managed Regression 与 Native Smoke

Managed Regression 覆盖 Value Type、Guard、Owner-aware Handle、Geometry/Transform Helper、Runtime Diagnostics、Viewport Interaction Policy 和 Native DTO ↔ Managed Result Mapping。

真实 Native Smoke 才能验证：

- C++ 编译/链接；
- `OcctNative.dll` 与 OCCT/第三方 DLL 加载；
- 实际几何/拓扑算法；
- Viewer/Selection；
- Mesh/Exchange；
- ABI Struct 在真实调用中的正确性。

## 7. ABI 校验方向

`344 Native == 344 P/Invoke` 可以发现增删遗漏，但仍不能证明参数类型/顺序、Struct layout、Enum value 完全一致。后续应继续强化签名级 ABI 校验，而不是增加更多源码字符串扫描。

## 8. 推荐流程

普通 Managed 修改：

```powershell
.\build.ps1 validate Release
.\build.ps1 managed Release
.\build.ps1 test Release
```

涉及 Native/ABI：

```powershell
.\build.ps1 all Release
.\build.ps1 smoke Release
```

单独更新 API 文档：

```powershell
.\build.ps1 docs Release
```

只准备 Binary SDK：

```powershell
.\build.ps1 dist Release
```

正式发布 API 文档 + main Binary SDK + demo：

```powershell
.\publish.ps1
```

本仓库不使用 GitHub Actions 代替真实 Windows/MSVC/OCCT 本地构建与发布门禁。
