# 网格与数据交换

Mesh 与 Exchange API 属于 Core，不依赖桌面窗口系统。

Bridge 提供可配置 Triangulation，以及基于 OCCT 7.9 契约 Toolkit 的 STEP Assembly、IGES、BREP、STL 等工程交换能力。

STEP 装配导入内部使用 XDE 保留 Hierarchy、Occurrence、Transform、Visibility、Color 和 Subshape Style，再投影成 Managed `OcctAssemblyDocument` Snapshot。

OCAF/XDE 不作为上层应用 Document/Persistence 架构。只要对应 OCCT Runtime 可用，这些 Core 语义在 Windows/Linux 保持一致。
