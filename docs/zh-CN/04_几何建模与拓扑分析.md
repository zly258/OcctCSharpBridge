# 04 几何建模与拓扑分析

本文集中说明 `OcctModelingSession` 的 Headless 建模、几何查询、拓扑分析和稳定拓扑引用能力。原先分散的 Managed Geometry、B-Spline、Topology Analysis、Shape Inspection 等文档统一合并到这里。

## 1. 基础几何与 B-Rep 构造

常见入口包括：

- Box、Cylinder、Cone、Sphere、Torus 等 Primitive；
- Line、Circle、Arc、Ellipse 等 Curve；
- Wire、Face、Shell、Solid 组装；
- Translation、Rotation、Scale、Mirror 等 Transform/Location。

示例：

```csharp
using var model = new OcctModelingSession();

var box = model.MakeBox(100, 80, 60);
var cylinder = model.MakeCylinder(
    new OcctPoint3d(50, 40, -10),
    OcctVector3d.UnitZ,
    12,
    80);

var cut = model.Cut(box, cylinder);
```

所有返回的 `OcctModelShape` 都绑定当前 Session。

## 3. Geometry Query

常用查询包括：

- Shape Bounds；
- Shape Type / Orientation / Closed / Valid / Tolerance；
- Vertex Point；
- Edge Endpoints；
- Edge Curve Type；
- Edge 参数点与切向；
- Face Surface Type；
- Face UV Bounds；
- Face Point/Normal；
- Shape Distance；
- Linear/Surface/Volume Properties。

精确几何结果应优先调用 Native OCCT，而不是用 Managed 近似替代。

## 4. Managed 几何工具

`OcctGeometryExtensions` 提供不需要 Native 的轻量计算：

```csharp
var a = new OcctPoint3d(0, 0, 0);
var b = new OcctPoint3d(100, 50, 0);
var midpoint = a.Lerp(b, 0.5);

var direction = new OcctVector3d(1, 1, 0);
var angle = direction.AngleTo(OcctVector3d.UnitX);
```

也包括：

- `AlmostEquals()`；
- AABB `Contains/Intersects/Union/Expanded`；
- UV Range；
- `OcctModelLocation` 与 `OcctTransform3d` 转换；
- Translation/Rotation/Scale Location；
- Matrix Multiply / Invert；
- Point/Vector Transform。

角度统一使用弧度。点变换包含平移，向量变换不包含平移。

## 5. B-Spline

Bridge 支持 B-Spline Curve/Surface 的结构化检查，重点暴露：

- Degree；
- Pole；
- Weight；
- Knot；
- Multiplicity；
- Rational/Periodic 状态；
- Surface U/V 控制网格信息。

这类接口适合参数化建模、曲线质量检查和其它平台几何复现。不要只把 B-Spline 转成离散点后丢失原始参数信息。

## 6. Topology 遍历

通用入口：

```csharp
var faces = model.GetSubshapes(shape, OcctShapeType.Face);
```

常用快捷接口：

```csharp
var vertices = model.GetVertices(shape);
var edges = model.GetEdges(shape);
var faces = model.GetFaces(shape);
var solids = model.GetSolids(shape);

var faceEdges = model.GetFaceEdges(face);
var wireEdges = model.GetWireEdges(wire);
var edgeVertices = model.GetEdgeVertices(edge);
var counts = model.GetTopologyCounts(shape);
```

大集合使用 Bulk Native ABI，避免逐项 `Count + At`。

## 7. 邻接分析

单个拓扑查询：

```csharp
var adjacentFaces = model.GetAdjacentFaces(rootShape, edge);
var incidentEdges = model.GetIncidentEdges(rootShape, vertex);
var incidentFaces = model.GetIncidentFaces(rootShape, vertex);
```

需要检查整个 Root Shape 时优先：

```csharp
var adjacency = model.AnalyzeEdgeAdjacency(rootShape);
```

分类语义：

- 0 个相邻 Face：Isolated；
- 1 个不同 Face：Boundary Candidate；
- 2 个不同 Face：Manifold Interior；
- 3 个及以上不同 Face：Non-Manifold Candidate。

`Boundary Candidate` 只是快速拓扑信号，不等于严格自由边界结论。

## 8. Free Bounds

Shell 开口、缝隙或 Sewing/Healing 前的严格检查使用：

```csharp
var result = model.AnalyzeFreeBounds(
    shape,
    tolerance: 1e-6,
    splitClosed: true,
    splitOpen: true);
```

结果区分 Closed Wire 与 Open Wire，并保留实际使用的 Tolerance。

推荐流程：

1. `GetTopologyCounts()`；
2. `AnalyzeEdgeAdjacency()`；
3. 查看 Non-Manifold；
4. 用 Boundary Candidate 做初筛；
5. `AnalyzeFreeBounds()` 做最终自由边界判断；
6. 确有需要再 Healing。

## 9. Shape Inspection

`InspectShape()` 用于生成不绑定具体业务规则的结构化审模快照。适合：

- 拓扑数量；
- Validity；
- Bounds；
- Tolerance；
- Surface/Curve 类型统计；
- 问题定位前的模型摘要。

Bridge 只提供结构化事实；“该模型是否符合某企业标准”仍由上层规则系统判断。

## 10. 惯性与质量属性

可分别获取：

```csharp
model.GetLinearInertiaProperties(shape);
model.GetSurfaceInertiaProperties(shape);
model.GetVolumeInertiaProperties(shape);
```

`OcctInertiaProperties` 包括：

- Mass；
- Center of Mass；
- Inertia Tensor；
- Principal Moments；
- Principal Axes；
- Radius of Gyration；
- 对称性信息。

## 11. Structured Edge/Edge Intersection

```csharp
var intersections = model.IntersectEdges(firstEdge, secondEdge);
```

返回值区分点交与重合区间，并保留源 Edge 的曲线参数范围，适合后续：

- 精确裁剪；
- 约束判断；
- 草图/曲线交互；
- 几何关系分析。

## 12. Operation History

Boolean/Feature 算法产生 History 时，可以查询 Generated / Modified / Removed 等拓扑演化信息。

History 的主要价值不是“记录命令历史”，而是回答：

```text
旧 Face/Edge 经过某次 OCCT 算法后变成了什么？
```

Document Undo/Redo 仍属于应用层。

## 13. Topology Reference

运行时 `SubshapeIndex` 不适合长期持久化。稳定引用使用：

```csharp
var reference = model.CreateTopologyReference(rootShape, subshape);
var resolved = model.ResolveTopologyReference(rootShape, reference);
```

Fingerprint 会综合：

- Topology Type；
- Curve/Surface Type；
- Measure；
- Center；
- Bounds；
- Tolerance；
- Orientation；
- Vertex/Edge/Face 邻接数量；
- Runtime Index Hint。

Index 只是低权重提示，不是主身份。

## 14. 性能建议

- 一次分析多个 Edge 时复用 `AnalyzeEdgeAdjacency()` 结果；
- 大集合优先 Bulk API；
- 不要在高频循环中重复 `GetSubshapes()` 后再逐项查询相同属性；
- Mesh、Inspection、History 等结果是快照，需要时再生成；
- 精确几何交给 OCCT，轻量向量/AABB 运算使用 Managed 工具。
