# OcctScript C# 参数化脚本编辑器总体架构

## 1. 分支定位

`script` 分支在 `main` 的 OCCT C# 封装基础上开发参数化脚本编辑器。`main` 保持纯封装库，脚本文档、表达式、命令注册、撤销重做和编辑器界面仅存在于 `script` 分支。

## 2. 第一阶段项目

- `OcctScript.Domain`：文档、参数、命令、字段和注册定义。
- `OcctScript.Expressions`：不依赖 UI 和 OCCT 的表达式解析与计算。
- `OcctScript.Serialization`：版本化 JSON、UTF-8 with BOM、原子保存。
- `OcctScript.Application`：参数计算和文档应用服务。
- `OcctScript.Geometry`：命令到 OCCT Shape 的构建接口与注册机制。

## 3. 关键约束

1. 不使用 OCAF/XDE。
2. JSON 仅保存参数、命令、引用和显示信息，不保存原生指针。
3. 解析器不识别具体命令类型，具体命令通过注册表扩展。
4. 领域层不引用 WPF 或 OCCT。
5. 所有几何构建通过 `ICommandShapeBuilder`。
6. 参数表达式直接使用参数名，不要求 `${}`。
7. 文件和源码统一采用 UTF-8 with BOM。
