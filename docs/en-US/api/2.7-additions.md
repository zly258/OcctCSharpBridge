# Bridge 2.7 Avalonia source additions

The standalone `avalonia` branch carries the Bridge 2.7 Core capabilities plus a cross-platform Viewer-hosting boundary.

Key 2.7 Core additions include `OcctAssemblyDocument` / `OcctAssemblyNode` STEP assembly snapshots, first-class `OcctPoint` / `OcctPointMarker`, surface-only resize, improved STEP/XDE style and occurrence handling, and the existing 134 Modeling API surface.

Avalonia branch-specific additions:

- `net10.0` Core and Avalonia targets;
- source platforms `windows-x64` + `linux-x64`;
- platform-neutral Native Surface initialization;
- one public `OcctAvaloniaViewport` on both systems;
- Windows backend: HWND → `WNT_Window`;
- Linux first Viewer backend: X11/XWayland XID → `Xw_Window`;
- `build.ps1` / `publish.ps1` for Windows;
- `build.sh` / `publish.sh` for Linux;
- no WinForms, WPF or sync dependency.

Native Wayland Viewer hosting is not claimed complete. The public viewport API is intentionally independent of the backend so another surface implementation can be introduced without changing consuming application code.
