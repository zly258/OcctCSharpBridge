# 几何建模与拓扑分析

`OcctModelingSession` 是 `main` 中 Headless 建模的 Owner，其语义与 WinForms、WPF、Avalonia 均解耦，并保持可被所有受支持 Consumer Host 复用。

Modeling 能力包括 Primitive、Boolean、Extrude、Revolve、Sweep、Loft、Fillet、Chamfer、Offset、Shelling、Healing、Mesh、Shape Validation、Geometry Evaluation、Topology Traversal、Adjacency、Intersection、Inertia 与 Operation History。

Shape Handle 只在所属 Modeling Session 生命周期内有效。产品级持久化 ID 由应用层维护；Bridge 提供 Topology Reference 能力用于建模操作后的子拓扑重识别。

高基数结果优先使用 Bulk Native API，避免在应用层逐 Face/Edge 形成 N+1 P/Invoke。
