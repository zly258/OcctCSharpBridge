# 运行时部署与诊断

`avalonia` 分支根据操作系统解析 Native Bridge：

```text
Windows: OcctNative.dll
Linux:   libOcctNative.so
```

Windows 默认开发路径：

```text
D:\tools\occt-vc144-64
```

Linux 默认开发路径：

```text
/usr/local/include/opencascade
/usr/local/lib
```

非默认开发或应用部署可以配置 `OCCT_ROOT`、`OCCT_BRIDGE_NATIVE_DIR` 及对应平台的 Dynamic Loader。

`avalonia` 分支保持源码型，不跟踪 Binary SDK 输出。业务应用部署时应自行携带与目标平台匹配的 Native Bridge 和 OCCT Runtime 依赖。

当前 Linux Viewer 运行需要 X11/XWayland；纯 Headless Modeling 不要求 Viewer Surface。
