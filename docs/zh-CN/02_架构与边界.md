# 架构与边界

`main` 保持 Bridge 与产品级 CAD/BIM 架构解耦：

```text
Application
   │
   ├─ OcctNet.WinForms ─┐
   └─ OcctNet.Wpf ──────┤
                         ▼
                      OcctNet
                         │
                    stable C ABI
                         │
                     OcctNative
                         │
                      OCCT 7.9
```

`OcctNet` 提供强类型 Managed Semantics，`OcctNative` 负责 C++/OCCT 边界；WinForms/WPF 都只依赖 Core，互不引用。

Document、Feature Tree、Command/Tool、Undo/Redo、捕捉、夹点和项目持久化属于上层应用职责。

XDE 可以在 STEP 装配交换内部使用，但不会暴露成应用层 OCAF Document。

Avalonia 单独放在 `avalonia` 分支，避免 Windows-only `net10.0-windows` 主契约限制跨平台 `net10.0` Host。
