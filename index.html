OPEN CASCADE × .NET

A clean OCCT bridge for Windows and cross-platform Avalonia applications

OcctCSharpBridge exposes OCCT 7.9.0 through a stable C ABI and strongly typed .NET 10 APIs. The Windows main branch provides WinForms/WPF hosts; the standalone Avalonia branch targets both Windows x64 and Linux x64.

CAPABILITIES

One OCCT foundation, explicit platform hosts

Core capabilities stay focused on geometry, topology, exchange, AIS and interaction while product documents and workflows remain in the consuming application.

01

Viewer & AIS

Camera, projection, display modes, material/color/transparency, transforms, text, dimensions, points, lighting and redraw batching.

02

Headless modeling

Primitives, Boolean, extrude, revolve, sweep, loft, fillet, chamfer, offset, shelling, healing and history.

03

Selection & interaction

Point/rectangle selection, detection, structured object identity, zoom, pan, rotation and world-point conversion.

04

Geometry & topology

Evaluation, curvature, projection, distance, adjacency, inertia, intersections, validation and topology references.

05

Meshing

Configurable triangulation with bulk node/triangle transfers and per-face provenance.

06

STEP assembly exchange

XDE-derived managed assembly snapshots preserve hierarchy, occurrences, transforms, visibility, colors and subshape styles.

07

Windows hosts

main keeps independent WinForms and WPF adapters on net10.0-windows.

08

Cross-platform Avalonia

avalonia exposes one OcctAvaloniaViewport API. Windows uses HWND/WNT_Window; Linux currently uses X11/XWayland XID/Xw_Window internally.

GET STARTED

Choose the branch by UI/platform requirement

Use main for Windows WinForms/WPF. Use avalonia directly for Avalonia on Windows or Linux; there is no sync dependency between them.

PowerShell / Bash
# Windows WinForms/WPF Bridge
git switch main
.\build.ps1 all Release -OcctRoot "D:\tools\occt-vc144-64"

# Cross-platform Avalonia on Windows
git switch avalonia
.\build.ps1 all Release -OcctRoot "D:\tools\occt-vc144-64"
.\build.ps1 avalonia-smoke Release -OcctRoot "D:\tools\occt-vc144-64"

# Cross-platform Avalonia on Linux
git switch avalonia
./build.sh all Release
./build.sh x11-smoke Release
./build.sh avalonia-smoke Release
