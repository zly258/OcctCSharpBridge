# 构建与发布

## Windows 构建

```powershell
.\build.ps1 build Release -OcctRoot "D:\tools\occt-vc144-64"
```

`build` 只编译 Native 与 Managed，不更新系统级 SDK。

## Windows 发布/安装

```powershell
.\publish.ps1 -OcctRoot "D:\tools\occt-vc144-64"
```

发布会构建并校验 Release Binary SDK，然后原子安装到：

```text
C:\Program Files\OcctCSharpBridge\SDK\3.0\win-x64
```

可通过 `OCCTCSHARPBRIDGE_SDK` 环境变量或 `-InstallRoot` 覆盖安装目录。写入 `Program Files` 通常需要管理员权限。

Windows Consumer 直接引用系统安装 SDK，不再维护仓库内同步副本。

## Native Viewport 首帧

WPF/Avalonia Host 自己负责第一次 Native 呈现。应用正常把 Viewport 放入 Visual Tree；依赖首帧已实际呈现的操作可等待 `HostState == Ready`。

`Ready` 表示 Viewport 已获得有效布局尺寸并至少完成一次 `ResizeSurface + Redraw`。不要通过模拟鼠标移动、固定 Dispatcher 延时、重复 `FitAll` 或额外启动 `Redraw` 来“唤醒”首帧。

## Linux

```bash
./build.sh build Release
./build.sh dist Release
```

Linux 仍采用源码构建方式。
