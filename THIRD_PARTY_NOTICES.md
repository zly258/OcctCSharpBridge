## Runtime closure dependencies

The Portable SDK is built from the configured OCCT 7.9.0 installation and follows the actual native dependency closure of the Bridge:

- Windows uses the PE import closure of `OcctNative.dll` and may include required OCCT modules, TBB/other OCCT third-party DLLs, and redistributable Microsoft Visual C++ runtime DLLs.
- Linux uses the ELF dependency closure of `libOcctNative.so` and may include required OCCT, TBB, FreeImage, or other non-system shared libraries. System components such as glibc, OpenGL, X11/Wayland libraries remain target-system dependencies.

The exact set of bundled runtime files depends on the OCCT distribution used to create the package. `package-manifest.json` records the files and SHA-256 hashes in each generated Portable SDK.
