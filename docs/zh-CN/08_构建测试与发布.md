# 构建、测试与发布

## Windows

```powershell
.\build.ps1 validate Release
.\build.ps1 managed Release
.\build.ps1 test Release
.\build.ps1 smoke Release -OcctRoot "D:\tools\occt-vc144-64"
.\build.ps1 viewport-smoke Release -OcctRoot "D:\tools\occt-vc144-64"
.\build.ps1 all Release -OcctRoot "D:\tools\occt-vc144-64"
```

`validate` 只检查版本、ABI 与基础构建配置。编译和测试是主要正确性门槛。

测试层级只有：

1. ManagedTests；
2. Modeling Smoke；
3. Avalonia Viewer Smoke。

WinForms/WPF 由真实项目编译覆盖，不维护重复窗口 Smoke。

正式 Windows 发布使用：

```powershell
.\publish.ps1 -OcctRoot "D:\tools\occt-vc144-64" -Zip
```

发布会执行 Release gate、生成 Portable SDK，并在隔离环境中运行一次 .NET 10 package smoke。

## Linux

```bash
./build.sh validate Release
./build.sh managed Release
./build.sh test Release
./build.sh smoke Release
./build.sh all Release
./build.sh avalonia-smoke Release
```
