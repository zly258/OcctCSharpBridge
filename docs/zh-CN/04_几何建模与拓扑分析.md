# 04 几何建模与拓扑分析

`OcctModelingSession` 是不依赖 Viewer 窗口的 Headless 建模边界。

## 建模

托管 API 覆盖 Primitive、Wire/Face、Boolean、Extrude、Revolve、Sweep、Loft、Fillet、Chamfer、Offset、Shelling、Healing 和操作 History。所有结果都保持明确的 Session 所有权。

## 几何分析

强类型查询覆盖 Curve/Surface Type、Parameter Range、UV Bounds、Evaluation、Derivative、Curvature、解析几何、Projection、Ray Hit、Distance 与 Inertia Properties。

## 拓扑分析

可遍历 Vertex、Edge、Wire、Face、Shell、Solid，并获取 Adjacency、Shape Inspection 等结构化结果。高基数结果尽量通过 Bulk ABI 一次复制，避免重复跨 Native 边界。

## 持久拓扑引用

`OcctTopologyReference` 用于描述并重新解析 Subshape 身份，面向受控建模变化，比直接保存瞬时 OCCT Handle 更适合作为上层关联信息。

## 显示 Headless Shape

`OcctEngine.Display(model, shape)` 会把 Headless Shape 复制进入 Viewer Presentation；Modeling Session 仍管理原建模 Handle。
