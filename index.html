Native CAD geometry infrastructure

Industrial geometry SDK for .NET CAD/BIM software.

OcctCSharpBridge exposes Open CASCADE Technology 7.9.0 through a stable native ABI and typed .NET APIs for geometry, BRep modeling, exchange and hardware-accelerated desktop viewports.

01 / Capabilities

Low-level by design.

核心页面按 SDK 技术产品来表达：几何内核、数据交换、视口和运行时契约，而不是营销式功能堆砌。

01

Geometry & BRep

Primitives, booleans, topology traversal, fillets, chamfers, meshing and physical properties.

02

STEP exchange

Assembly-aware STEP AP214/AP242 import and export with hierarchy, names, colors and metadata.

03

Viewer & AIS

Hardware-accelerated OCCT visualization with picking, highlighting, camera control and native desktop hosting.

04

Runtime contract

Stable ABI 5 boundary, typed managed API and explicit runtime validation for predictable SDK consumption.

03 / Developer SDK

Build once. Consume as an SDK.

安装、引用和职责边界都按开发者文档方式表达。

Windows · install/update SDK
.\publish.ps1 -OcctRoot "D:\tools\occt-vc144-64"
Linux · build
./build.sh build Release
Application boundary. The Bridge remains a low-level geometry / modeling / viewer wrapper. Documents, feature trees, commands, undo/redo, snapping, grips, catalogs and project semantics belong to applications built on top of it.
