Linux x64

CONSUMER WORKFLOW

Build the SDK, validate it, then consume it

Demo synchronization verifies platform contract, source commit and manifest hashes before applications are built or published.

01Build SDK

Generate the platform Binary SDK from main.

02Synchronize

Copy the validated SDK into demo/dist/<rid>.

03Build & run

Compile only the hosts supported by the current OS.

04Publish

Create independent application packages with runtime closure.

Windows x64 · PowerShell
# SDK
git switch main
.\build.ps1 dist Release

# Demo
git switch demo
.\sync.ps1
.\build.ps1 all Release
.\publish.ps1 all Release
Linux x64 · Bash
# SDK
git switch main
./build.sh dist Release

# Demo
git switch demo
./sync.sh
./build.sh all Release
./publish.sh Release

Bridge licensing and application linking are documented separately
