CAPABILITIES

为轻量 CAD 与工程软件准备的核心能力

桥接层只解决几何、显示与交互问题，把业务对象、文档生命周期和持久化留给上层应用。

01

Viewer 与 AIS

相机、投影、显示模式、材质、颜色、透明度、尺寸、文字、Fit、批量更新与高亮。

02

无窗口建模

基础体、布尔、拉伸、旋转、扫掠、放样、圆角、倒角、偏移、抽壳、修复与历史关系。

03

CAD 选择与交互

点选、框选、选择集同步、可选择状态、原始输入转发，以及可关闭的默认视口交互。

04

稳定对象关联

ApplicationTag 将应用层 EntityId 与 Viewer 对象稳定关联；几何可原位更新而不破坏显示状态。

05

几何查询与分析

拓扑遍历、解析几何参数、曲线/曲面导数、曲率、质量属性、投影、射线、距离与网格。

06

工程文件交换

面向纯 Shape 的 STEP、IGES、BREP、STL 导入导出，避免把应用文档模型耦合到桥接层。

DESIGN

明确的分层边界

不使用 OCAF/XDE 承担应用文档职责。桥接层保持通用，上层可以自由实现 AutoCAD 风格文档、撤销重做和 JSON 持久化。

01

应用对象不依赖 Viewer ID

使用 ApplicationTag 建立稳定关联，Viewer 对象删除重建也不会改变业务实体身份。

02

几何更新不重建显示对象

UpdateShape 原位替换 AIS_Shape，保留外观、局部变换、选择和可选择状态。

03

应用可以完全接管交互

EnableDefaultInteraction=false 后，宿主只转发原始输入，适合自定义 Tool、捕捉、动态预览和工作平面。

04

转换后的空间状态保持一致

Fit、场景包围盒和定位逻辑基于显示变换后的几何，避免对象移动后镜头仍回到原位置。

WINFORMS / WPF

同一桥接层，两套桌面 Demo

Demo 分支用于验证完整 CAD 交互、菜单、本地化、API Center 与发布流程；main 继续保持纯净可复用。

BRANCHES

按职责拆分，而不是把所有内容堆在 main

main可复用 OCCT C++ / C# 桥接核心↗ demoWinForms / WPF 完整示例与发布工具↗ script参数化脚本方向的独立实验分支↗ website本项目静态介绍站点与 GitHub Pages 源码↗
