# 构建、测试与发布

`main` 是 Windows x64 Bridge，因此使用 PowerShell 构建链。

```powershell
.\build.ps1 validate Release
.\build.ps1 native Release -OcctRoot "D:\tools\occt-vc144-64"
.\build.ps1 managed Release
.\build.ps1 test Release
.\build.ps1 smoke Release -OcctRoot "D:\tools\occt-vc144-64"
.\build.ps1 docs Release
.\build.ps1 dist Release -OcctRoot "D:\tools\occt-vc144-64"
```

静态校验包括版本/ABI、架构边界、Bulk ABI、Native Source Inventory 和 Native/PInvoke/API Surface 精确匹配。

`managed` 只构建：

```text
OcctNet
OcctNet.WinForms
OcctNet.Wpf
```

`dist` 输出 `dist/win-x64`，不包含 Avalonia。

正式发布：

```powershell
.\publish.ps1 -OcctRoot "D:\tools\occt-vc144-64"
```

当前发布链不使用 NuGet，也不使用 GitHub Actions。Avalonia Windows/Linux 构建及 `.sh` 脚本全部位于 `avalonia` 分支。
