# Bridge 2.7 main 源码新增能力

`main` 的 Bridge 2.7 继续保持 Windows x64 Core + WinForms + WPF 架构，同时扩展可复用 Core。

重点包括 `OcctAssemblyDocument` / `OcctAssemblyNode` STEP Assembly Snapshot、一等 `OcctPoint` / `OcctPointMarker`、Surface-only Resize、STEP/XDE Occurrence/Style Round-trip 完善，以及当前 134 个 Modeling API。

main 源码契约仍为 Windows-only：`net10.0-windows`、349 Native Export / 349 P/Invoke、113 个 Public .NET Type。Avalonia 不属于 main，独立位于 `avalonia` 分支。
