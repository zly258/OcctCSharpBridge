# 快速开始

OcctCSharpBridge 以平台 Binary SDK 和可选的 Portable SDK Runtime Closure 交付。普通应用项目应直接消费二进制 SDK，不需要编译或复制 Bridge 实现源码。

## 1. 选择产物

**最小 Binary SDK** 用于编译引用和受控构建自动化：

```text
win-x64: OcctNative.dll + OcctNet*.dll + contract/manifest
linux-x64: libOcctNative.so + OcctNet.dll + OcctNet.Avalonia.dll + contract/manifest
```

**Portable SDK** 用于应用部署，在最小 SDK 基础上增加：

```text
runtime/
occt/resources/
package-manifest.json
License / Notice
```

第三方正式项目建议使用从 `main` 生成并经过审查的 Portable SDK。完整接入方式见 [第三方项目消费 SDK](09_第三方项目消费SDK.md)。

## 2. 兼容契约

当前 Bridge 契约：

- Bridge `3.0.0-preview.1`
- 仅 ABI 5
- OCCT 7.9.0
- Windows x64 / Linux x64
- Binary SDK 最低 TFM：.NET 8
- Consumer 运行时：.NET 8、.NET 9、.NET 10
- WinForms/WPF：仅 Windows
- Avalonia/Core：提供 Windows/Linux Managed Surface

Bridge 源码使用稳定版 .NET 10 SDK 构建，基线为 `10.0.100`，使用 `latestFeature` Roll-forward；**不要求精确 `10.0.303`**。

## 3. 引用 Managed 程序集

Headless/Core 项目只需要 `OcctNet.dll`：

```xml
<ItemGroup>
  <Reference Include="OcctNet">
    <HintPath>$(OcctBridgeSdkRoot)/OcctNet.dll</HintPath>
    <Private>true</Private>
  </Reference>
</ItemGroup>
```

Avalonia 额外引用 `OcctNet.Avalonia.dll`；WinForms 引用 `OcctNet.WinForms.dll`；WPF 引用 `OcctNet.Wpf.dll`。项目不应引用自己没有使用的 UI Adapter。

可以在项目中统一定义 SDK Root：

```xml
<PropertyGroup>
  <OcctBridgeSdkRoot>$(MSBuildThisFileDirectory)external/OcctCSharpBridge/win-x64</OcctBridgeSdkRoot>
</PropertyGroup>
```

## 4. 配置 Runtime

使用 Portable SDK 布局部署时，将 Managed DLL、`runtime/` 和 `occt/` 一并放入最终应用包，并在创建第一个 Native-backed 对象之前配置 Bridge：

```csharp
using OcctNet;

OcctRuntime.Configure();

using var model = new OcctModelingSession();
var box = model.MakeBox(100, 80, 10);
model.ExportStep(box, "box.step");
```

`OcctRuntime.Configure()` 会解析应用本地 Runtime 和 OCCT Resources。禁止把一个 SDK 的 Native/runtime 与另一个 Source Commit 的 Managed DLL 混用。

## 5. 从源码快速生成 Consumer SDK

Bridge 维护者或受控内部 Consumer 可以只生成最新 Binary SDK，不执行完整 Release QA：

Windows：

```powershell
.\build.ps1 dist Release -OcctRoot "D:\tools\occt-vc144-64"
```

Linux：

```bash
./build.sh dist Release
```

这是 **Consumer Artifact 快路径**：只进行必要的 Contract Check、Native + Managed 构建和 Manifest/SDK 生成，不执行 ManagedTests、Consumer Matrix、Core Smoke 或任何 Viewport/窗口 Smoke。

Bridge 自身的完整验证和正式发布仍使用：

```powershell
.\build.ps1 sdk Release -OcctRoot "D:\tools\occt-vc144-64"
.\publish.ps1 -OcctRoot "D:\tools\occt-vc144-64" -Zip
```

```bash
./build.sh all Release
./publish.sh
```
