# 07 运行时部署与诊断

## 运行时组成

应用加载 `OcctNet*.dll` 与 `OcctNative.dll`；`OcctNative.dll` 继续依赖构建时使用的 OCCT 7.9.0 Toolkit 和必要第三方 Runtime。

`OcctRuntime` 可从显式路径、`OCCT_ROOT` 或 `CASROOT` 配置运行环境。

## 常见启动问题

遇到 `DllNotFoundException`、Win32 126 或进程在 Viewport 创建前退出，依次检查：

1. 应用目录是否有匹配版本的 `OcctNative.dll`；
2. OCCT 7.9.0 `TK*.dll` 是否可解析；
3. 必要第三方 DLL 是否存在；
4. 所有 Native 二进制是否均为 x64；
5. Managed Bridge Version 与 Native Bridge Version/ABI 是否兼容。

## UI Host

WinForms、WPF、Avalonia 都基于 Windows HWND 承载 OCCT Viewer。Avalonia 的 Shell `MainWindowHandle` 可能晚于进程启动才可见，因此不能仅用固定 5 秒 `MainWindowHandle` 超时判断启动失败，应优先看进程是否退出以及真实异常。
