# 架构与边界

`avalonia` 分支只保留两个公开 Managed Layer：

```text
Application
    │
OcctNet.Avalonia
    │
  OcctNet
    │
stable C ABI
    │
OcctNative
 ├─ Windows: WNT_Window
 └─ Linux:   Xw_Window
```

`OcctNet` 不依赖 UI Framework；`OcctNet.Avalonia` 只依赖 Core，不引用 WinForms/WPF。

公开 Host 是平台无关 API，窗口系统差异隔离在 Adapter/Native Surface 内部。

Document、Feature Tree、Command/Tool、Undo/Redo、捕捉、夹点和持久化仍属于上层应用。

Native Wayland 属于后续 Backend，不应要求新增一套公开 Viewport 类型。
