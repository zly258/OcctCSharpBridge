# OcctScript 命令架构与第一阶段功能

## 1. Command 设计结论

第一阶段继续采用“文档命令实例 + 命令元数据 + Shape Builder 注册”的架构，但补齐原版本缺失的拓扑约束、引用关系和依赖排序。该设计合理，原因如下：

1. `ScriptCommand` 只保存类型、字段、引用、变换和显示信息，不保存 OCCT 原生指针。
2. `CommandDefinition` 描述字段名称、显示名称、字段类型、默认值、单位、必填性、允许引用的拓扑类型和输出拓扑。
3. `ICommandShapeBuilder` 负责把一种命令构建为 `OcctModelShape`，新增命令不需要修改解析器。
4. `CommandDependencyResolver` 根据命令引用进行拓扑排序，不再依赖列表顺序碰巧正确。
5. `DocumentValidator` 在构建前检查缺失引用、自引用、引用数量、类型不兼容和循环依赖。
6. 所有命令统一经过缩放、旋转和平移，避免每个 Builder 重复实现变换。

因此，界面、序列化和构建器之间通过元数据连接，不使用巨型 `switch` 硬编码整个编辑器。

## 2. 第一阶段命令范围

### 2.1 曲线与线框

- Vertex：三维点。
- Line：起点和终点创建直线边。
- Polyline：点列表创建开放或闭合折线。
- Circle：圆心、法向和半径创建圆边。
- Arc：起点、中间点和终点创建圆弧。
- Rectangle：原点、X 方向、法向、宽度和高度创建矩形线框。
- Wire：将多个 Edge 或 Wire 合并为 Wire。

### 2.2 面

- Face：将闭合 Edge 或 Wire 转换为平面 Face。
- PlaneFace：直接创建矩形平面 Face。

由此支持“多条线组成闭合线框，再由线框生成面”。

### 2.3 基本体

- Box。
- Cylinder。

基本体保留用于快速创建工具体和验证布尔操作，但不作为参数化建模的唯一入口。

### 2.4 特征

- Extrude：Edge 拉伸生成 Face；Wire 拉伸生成 Shell；Face 拉伸生成 Solid。
- Revolve：Edge、Wire 或 Face 围绕指定轴旋转。
- Sweep：截面沿路径扫掠。
- Loft：两个及以上截面放样，可选择实体或曲面、直纹或平滑。

### 2.5 布尔

- Fuse：并集。
- Cut：差集。
- Common：交集。
- Section：截交线。

布尔命令支持模糊容差，并保留 OCCT 算法报告中的警告和错误。

## 3. 构建流程

1. 校验文档和参数名称。
2. 计算参数表达式。
3. 收集命令引用关系。
4. 对命令进行拓扑排序。
5. 按顺序调用已注册 Builder。
6. 校验实际输出拓扑是否符合命令定义。
7. 应用统一变换。
8. 将最终 Shape 复制到 AIS 视图。
9. 输出逐命令构建状态和 OCCT 算法报告。

命令失败后不会伪造 Shape；依赖该命令的后续命令会明确报告引用未生成。

## 4. 编辑器界面

编辑器采用浅色工程软件风格：顶部菜单和紧凑工具栏；左侧命令库、模型命令和参数表；中部 OCCT 三维视图；右侧命令说明、输出拓扑、统一变换和元数据驱动字段表；底部构建输出。

命令库由 `CommandRegistry` 自动生成，界面不再只写死 Box 和 Cylinder。

## 5. 语言

- 默认语言：英文 `en-US`。
- 可切换语言：中文 `zh-CN`。
- 菜单、命令名称、命令说明、字段名称、字段类型和状态文字均来自资源字典。
- `.ocsproj` 内部命令类型和字段键始终使用英文稳定键，切换界面语言不会破坏文件兼容性。

## 6. 示例

`samples/Scripts/FeaturePipeline.ocsproj` 展示完整链路：四条 Line 创建矩形边界；Wire 合并线段；Face 生成平面；Extrude 生成基础实体；Cylinder 创建孔工具体；Cut 输出最终带孔实体。
