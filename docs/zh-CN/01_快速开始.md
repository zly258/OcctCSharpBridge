# 01 快速开始

## 环境要求

- Windows 10/11 x64
- .NET SDK 10.0.302
- 构建 Native Bridge 时需要 CMake 3.21+ 与兼容的 MSVC
- Open CASCADE Technology 7.9.0

## 当前源码与已发布 SDK

当前源码契约是 **Bridge 2.7.0 / ABI 4**。正式已发布 Binary SDK 始终以仓库实际跟踪的 `main/dist/win-x64` 为准；请读取 `dist/win-x64/bridge-contract.json` 获取真实版本与 API 契约，不在文档中重复硬编码另一份发布版本。

## 从源码构建 Bridge

```powershell
.\build.ps1 validate Release
.\build.ps1 all Release -OcctRoot "D:\tools\occt-vc144-64"
```

## Headless 建模

```csharp
using OcctNet;

using var model = new OcctModelingSession();
var box = model.MakeBox(100, 80, 20);
var hole = model.MakeCylinder(new OcctPoint3d(50, 40, -5), OcctVector3d.UnitZ, 10, 30);
var result = model.Cut(box, hole);
model.ExportStep(result.Shape, "result.step");
```

## 2.7 源码：STEP 装配读取

```csharp
using var engine = new OcctEngine();
OcctAssemblyDocument doc = engine.ImportStepDocument("assembly.step");
```

普通 Shape 导入继续使用 `ImportStep()`；需要真实 Assembly/Instance/Part、Occurrence Transform 和样式时使用 `ImportStepDocument()`。

## 正式发布 Binary SDK

```powershell
.\publish.ps1 -OcctRoot "D:\tools\occt-vc144-64"
```

随后在 demo 分支：

```powershell
git switch demo
.\sync.ps1
.\build.ps1 all Release
.\run.ps1 wpf Release
```

`sync.ps1` 始终复制并输出 `main` **实际已发布**的 SDK 契约。
