# 快速开始

`avalonia` 是独立源码分支，没有 sync、跟踪式 `dist`、分支内 Binary SDK 发布流程，也不依赖 WinForms/WPF。

## Windows

```powershell
.\build.ps1 all Release -OcctRoot "D:\tools\occt-vc144-64"
.\build.ps1 avalonia-smoke Release -OcctRoot "D:\tools\occt-vc144-64"
```

## Linux

基线：Linux x64、.NET SDK 10.0.302、OCCT 7.9.0、CMake 3.21+、C++17 Compiler，以及当前 Viewer Backend 所需的 OpenGL/X11 开发库。

默认路径：

```text
/usr/local/include/opencascade
/usr/local/lib
```

```bash
./build.sh all Release
./build.sh avalonia-smoke Release
```

`all` 执行 Native + Managed + ManagedTests + Headless Smoke。`avalonia-smoke` 单独执行，因为 Linux Viewer 验证需要 X11/XWayland 桌面会话。

## Avalonia 使用

Windows/Linux 上层代码一致：

```csharp
var viewport = new OcctAvaloniaViewport();
```

业务代码不应依赖 HWND、XID、`WNT_Window` 或 `Xw_Window`。
