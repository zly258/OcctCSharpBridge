WORKFLOW

Build, validate, consume

Demo verifies the contract before building or publishing.

01Build SDK

Generate the Binary SDK from main.

02Sync

Copy the SDK into demo/dist/<rid>.

03Build & run

Compile the hosts for the current OS.

04Publish

Package apps with their runtime closure.

Windows x64 · PowerShell
# SDK
git switch main
.\build.ps1 dist Release

# Demo
git switch demo
.\sync.ps1
.\build.ps1 all Release
.\publish.ps1 all Release
Linux x64 · Bash
# SDK
git switch main
./build.sh dist Release

# Demo
git switch demo
./sync.sh
./build.sh all Release
./publish.sh Release
