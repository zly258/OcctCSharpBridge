# 运行时部署与诊断

Bridge 3 是 **ABI5-only、跨平台 x64 SDK**。源契约同时支持 `windows-x64` 与 `linux-x64`，具体 UI 适配器仍按框架和平台边界拆分。

Native Bridge：

```text
Windows x64: OcctNative.dll
Linux x64:   libOcctNative.so
```

Windows 默认开发环境 OCCT 路径：

```text
D:\tools\occt-vc144-64\inc
D:\tools\occt-vc144-64\win64\vc14\lib
D:\tools\occt-vc144-64\win64\vc14\bin
```

Linux 默认使用 `/usr/local/include/opencascade` 与 `/usr/local/lib`，也可以通过构建环境覆盖。

`OcctRuntime` 负责解析配置的 Native Bridge/OCCT Runtime，并在运行库无法加载时提供诊断信息。

`OcctNet.dll` 与 Native Bridge 必须来自**同一次 Bridge 构建**。运行时校验要求 ABI 必须为 5，并且 Bridge 版本完全一致；不再把更高或更低的 Native Bridge 版本作为兼容替代。

`dist/win-x64` 与 `dist/linux-x64` 都是 Bridge Binary SDK，不等于完整应用 Runtime Closure。实际应用仍需根据目标平台、发布策略和第三方许可证部署 OCCT 及相关运行库。

WinForms、WPF 适配器仅面向 Windows；核心 `OcctNet` 与 Avalonia 适配器构成 Linux 消费端使用的跨平台托管层。
