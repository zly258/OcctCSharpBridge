# 快速开始

Bridge 3 的正式 SDK 源统一维护 Native Core、`OcctNet`、WinForms、WPF 与 Avalonia Adapter。源码契约支持 Windows x64 与 Linux x64。`demo` / `demo-dev` 是唯一 Consumer 线：Windows x64 使用 WinForms、WPF、Avalonia，Linux x64 仅使用 Avalonia。

## 环境

Windows：

- Windows x64
- Visual Studio 2022 C++ Toolchain
- .NET SDK **10.0.303 精确版本**
- OCCT 7.9.0
- CMake 3.21+

默认 OCCT SDK：

```text
D:\tools\occt-vc144-64
```

Linux x64 使用同一 ABI5-only Core 与 Avalonia Managed Adapter，具体环境与命令见 [构建、测试与发布](08_构建测试与发布.md)。

## Windows 构建

推荐完整验证：

```powershell
.\build.ps1 all Release -OcctRoot "D:\tools\occt-vc144-64"
```

按需执行：

```powershell
.\build.ps1 validate Release
.\build.ps1 native Release
.\build.ps1 managed Release
.\build.ps1 test Release
.\build.ps1 smoke Release -OcctRoot "D:\tools\occt-vc144-64"
```

`managed` 构建 `OcctNet`、`OcctNet.WinForms`、`OcctNet.Wpf` 与 `OcctNet.Avalonia`。Managed 相关 target 会先解析能够使用精确 .NET SDK 10.0.303 的 `dotnet.exe`。

## 统一 Demo Consumer

SDK 源码不包含第二套 Demo Core/Native 实现。正式 `demo` 分支同步 `main` 生成的 Binary SDK，并提供：

- Windows x64：WinForms、WPF、Avalonia；
- Linux x64：仅 Avalonia。

## 最小建模示例

```csharp
using OcctNet;

using var model = new OcctModelingSession();
var box = model.MakeBox(100, 80, 10);
var hole = model.MakeCylinder(new OcctPoint3d(50, 40, -5), OcctVector3d.UnitZ, 8, 20);
var result = model.Cut(box, hole);
model.ExportStep(result.Shape, "plate.step");
```
