# Bridge 2.7 Avalonia 源码新增能力

独立 `avalonia` 分支在 Bridge 2.7 Core 基础上增加了跨平台 Viewer Host 边界。

2.7 Core 重点包括 `OcctAssemblyDocument` / `OcctAssemblyNode` STEP Assembly Snapshot、一等 `OcctPoint` / `OcctPointMarker`、Surface-only Resize、STEP/XDE Style/Occurrence 完善，以及现有 134 个 Modeling API。

Avalonia 分支专项变化：

- Core/Avalonia Target 统一为 `net10.0`；
- Source Platform 为 `windows-x64 + linux-x64`；
- 增加平台无关 Native Surface 初始化；
- Windows/Linux 对外统一 `OcctAvaloniaViewport`；
- Windows Backend：HWND → `WNT_Window`；
- Linux 第一阶段 Viewer Backend：X11/XWayland XID → `Xw_Window`；
- Windows 使用 `build.ps1` / `publish.ps1`；
- Linux 使用 `build.sh` / `publish.sh`；
- 不依赖 WinForms、WPF 或 sync。

当前不宣称 Native Wayland Viewer 已完成；公开 Viewport API 已与 Backend 解耦，后续增加 Surface Backend 不要求业务代码改用其它控件。
