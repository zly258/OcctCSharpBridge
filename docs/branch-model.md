# Branch Model

Target branch architecture:

- `main` — formal Bridge SDK source.
- `main-dev` — Bridge SDK development.
- `demo` — formal unified Demo consumer.
- `demo-dev` — Demo development.
- `website` — project website.
- `backup/*` — historical backups; leave unchanged.

Retired after migration:

- `avalonia`
- `avalonia-dev`

Avalonia remains a supported SDK adapter and Demo host; only the standalone Avalonia branches are retired.
