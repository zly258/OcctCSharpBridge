Repository Architecture

Three independent responsibilities with zero duplicated Bridge implementation.

main / main-dev SDK SOURCE

The sole Bridge SDK source tree: Native C++ Core (ABI5), OcctNet, WinForms/WPF/Avalonia adapters, ABI compatibility verification, and Binary SDK packaging.

demo / demo-dev CONSUMER APPS

Single consumer application tree. Windows hosts WinForms, WPF, and Avalonia; Linux hosts Avalonia. Consumes Binary SDK dist payloads with runtime verification.

website PORTAL

Minimalist static presentation portal: contract specs, platform matrix, capabilities, demo previews, and documentation index.

Core Capabilities

Comprehensive geometry, topology, exchange, and visualization engine.

01. Viewer & AIS Viewport

Hardware-accelerated 3D viewport, camera projections, Triedron coordinate system, ViewCube navigation cube, ray picking, and dynamic highlighting.

02. Headless BRep Modeling

Full BRep primitives (box, cylinder, sphere, torus, prism, revolution), boolean operations (fuse, cut, common), fillets, and chamfers without UI context.

03. Topology & Measurement

TopoDS entity traversal (compound, solid, shell, face, wire, edge, vertex), bounding box, surface area, volume, and center of mass calculations.

04. Meshing & Tessellation

High-performance BRepMesh triangulation with configurable linear deflection and angular deflection tolerances for rendering and analysis.

05. STEP Assembly Exchange

STEP AP214 and AP242 reader and writer supporting assembly tree hierarchy, color preservation, item naming, and metadata exchange.

06. Runtime Contract Check

Automated runtime validation against bridge-contract.json ensuring strict ABI5 compliance and zero binary drift across platforms.

Workflow & Commands

Build Binary SDK from main, sync into demo, validate, and publish.

Windows x64 · PowerShell 
# 1. Build SDK on main
git switch main
.\build.ps1 dist Release

# 2. Sync and run Demo on demo
git switch demo
.\sync.ps1
.\build.ps1 all Release
.\publish.ps1 all Release
Linux x64 · Bash 
# 1. Build SDK on main
git switch main
./build.sh dist Release

# 2. Sync and run Demo on demo
git switch demo
./sync.sh
./build.sh all Release
./publish.sh Release
