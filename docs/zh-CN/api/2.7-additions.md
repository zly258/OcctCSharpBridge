# Bridge 2.7 源码 API 新增项

本页记录已经根据源码核对的 2.7 新增接口；完整生成式 API Reference 等待下一次 Windows 正式生成。

## STEP 装配模型

新增公开类型：

```csharp
public enum OcctAssemblyNodeKind { Assembly = 0, Instance = 1, Part = 2 }

public readonly record struct OcctAssemblyColor(double R, double G, double B, double A = 1.0);
public readonly record struct OcctAssemblyTransform3d(/* 12 个仿射分量 */);
public readonly record struct OcctAssemblyStyle(
    bool Visible,
    OcctAssemblyColor? SurfaceColor,
    OcctAssemblyColor? CurveColor);
public readonly record struct OcctAssemblySubshapeStyle(
    OcctShapeType ShapeType,
    int SubshapeIndex,
    OcctAssemblyStyle Style);

public sealed class OcctAssemblyNode;
public sealed class OcctAssemblyDocument;
```

`OcctAssemblyNode` 暴露稳定 Id/Index/Parent 信息、`Kind`、`Name`、`ReferenceName`、可选 `Shape`、Style、Local/Global Transform、Subshape Style、`Parent` 与 `Children`。

`OcctAssemblyDocument` 暴露 `SourcePath`、`PrimaryShape`、`Nodes`、`Roots`、`Assemblies`、`Instances` 和 `Parts`。

新增 `OcctEngine` 入口：

```csharp
public OcctAssemblyDocument ImportStepDocument(string filePath);
```

该方法完成正常 STEP 导入后读取 XDE 装配快照，并投影为托管 occurrence tree；原 `ImportStep()` 继续保留。

## 一等 Point Presentation

`OcctObjectKind` 新增 `Point = 5`。

```csharp
public enum OcctPointMarker
{
    Point = 0, Plus = 1, Star = 2, X = 3,
    Circle = 4, CirclePoint = 5, CirclePlus = 6,
    CircleStar = 7, CircleX = 8,
    Ring1 = 9, Ring2 = 10, Ring3 = 11, Ball = 12
}

public sealed class OcctPoint : OcctObject;
```

新增 `OcctEngine` 方法：

```csharp
public OcctPoint AddPoint(
    OcctPoint3d position,
    OcctPointMarker marker = OcctPointMarker.CirclePoint,
    double scale = 3.0,
    System.Drawing.Color? color = null);

public void SetPointPosition(OcctPoint point, OcctPoint3d position);
public void SetPointStyle(
    OcctPoint point,
    OcctPointMarker marker,
    double scale,
    System.Drawing.Color color);
```

Native 使用真正的 `AIS_Point + Geom_CartesianPoint`，不需要用 BRep Vertex 模拟 Point/捕捉点/夹点。

## 仅同步 Surface 的 Resize

新增：

```csharp
public void ResizeSurface();
```

该方法只同步 OCCT Render Surface 与 Native Window 尺寸，不立即绘制 Frame，使 UI Adapter 可以合并连续 Resize，再统一调用一次 `Redraw()`。

## 契约状态

上述接口属于源码 **Bridge 2.7.0 / ABI 4**。当前被跟踪 Binary SDK 仍为 2.6.0；Binary 消费者需要等 2.7 在 Windows 正式发布后才能获得这些新增 API。
