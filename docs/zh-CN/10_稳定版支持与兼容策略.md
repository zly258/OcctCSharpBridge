# 3.x 支持边界

`bridge-contract.json` 记录 Bridge 版本、ABI、OCCT、.NET 和平台事实。

- Windows x64：官方预编译平台。
- Linux x64：源码构建平台。
- Native ABI：当前仅 ABI 5。
- Managed：项目直接多目标构建 .NET 8 / 9 / 10。
- 同一 `OcctEngine` 或 `OcctModelingSession` 默认不保证并发线程安全。
- Handle/Object ID 与所属 Engine/Session 绑定。
- 普通 Modeling 数值使用应用自身的一致单位约定。
- Managed DLL、Native runtime、OCCT 资源和 Manifest 应来自同一构建。

仓库不维护旧 ABI Shim、迁移入口或冻结 API 清单。需要破坏 ABI 时应明确修改 Bridge/ABI 版本，而不是增加兼容层。
