# Bridge 2.7 main source additions

Bridge 2.7 on `main` keeps the Windows x64 Core + WinForms + WPF architecture while extending the reusable Core.

Key 2.7 additions include `OcctAssemblyDocument` / `OcctAssemblyNode` STEP assembly snapshots, first-class `OcctPoint` / `OcctPointMarker`, surface-only resize, improved STEP/XDE occurrence/style round-trip behavior, and the current 134 Modeling API surface.

The `main` source contract remains Windows-only (`net10.0-windows`, 349 Native exports / 349 P/Invoke mappings, 113 public .NET types). Avalonia is not part of main and is developed independently on the `avalonia` branch.
