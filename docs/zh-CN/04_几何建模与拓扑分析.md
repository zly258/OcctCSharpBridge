# 几何建模与拓扑分析

`OcctModelingSession` 提供与 Avalonia Viewer 解耦的 Headless 建模能力，因此 Windows/Linux 都可以在不创建 Viewport 的情况下使用 Core。

能力包括 Primitive、Boolean、Extrude/Revolve/Sweep/Loft、Fillet/Chamfer、Offset/Shelling、Healing、Validation、Geometry Evaluation、Topology Traversal、Adjacency、Intersection、Inertia、Mesh 与 Operation History。

Shape Handle 属于其 Owner Session；产品级持久化 Identity 仍由应用层管理。Topology Reference 用于建模操作后的子拓扑重识别。

高基数结果使用 Bulk Native API，避免 N+1 Interop。
