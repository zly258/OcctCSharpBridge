# OcctScript 编辑器第一阶段

## 已实现范围

- WPF 主窗口与 OCCT 三维视图。
- 默认英文界面，运行时切换简体中文。
- 新建、打开、保存 `.ocsproj` 文档。
- 参数名称、表达式和单位编辑；参数重命名时自动更新表达式引用。
- 元数据驱动的命令库，不在界面中为每种命令单独编写属性页。
- Vertex、Line、Polyline、Circle、Arc、Rectangle、Wire。
- Face、PlaneFace。
- Box、Cylinder。
- Extrude、Revolve、Sweep、Loft。
- Fuse、Cut、Common、Section。
- 命令引用、引用列表、点、向量、点列表、表达式和布尔字段编辑。
- 命令名称、启用状态、字段和变换的撤销、重做。
- 引用依赖排序、引用类型校验、循环依赖检查和输出拓扑校验。
- 参数计算、真实 OCCT 几何构建及 AIS 显示。
- 命令列表与三维视图双向选择。
- 轴测、前视、俯视、左视、右视和适合窗口。
- 构建错误、警告和 OCCT 算法报告。

## 界面结构

- 左侧：命令库、模型命令、参数表。
- 中间：OCCT 三维视图。
- 右侧：命令说明、输出拓扑、位置、旋转、缩放和命令字段。
- 底部：构建输出。

编辑器采用浅色工程软件风格，减少图标和装饰性元素，强调命令层级、参数和构建状态。

## 运行方式

1. 使用 x64 配置编译原生 `OcctNative`。
2. 编译 `OcctBridge.sln` 或直接编译 `src/OcctScript.Editor/OcctScript.Editor.csproj`。
3. 确保 OCCT 运行库和 `OcctNative.dll` 已复制到编辑器输出目录。
4. 启动 `OcctScript.Editor`。
5. 可打开 `samples/Scripts/FeaturePipeline.ocsproj` 验证线、面、拉伸和布尔完整链路。
