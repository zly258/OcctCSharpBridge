# 06 网格与数据交换

本文说明 `OcctModelingSession` 的 Triangulation、Mesh 数据、Face 来源追溯以及 STEP/IGES/BREP/STL 数据交换。

## 1. Triangulation

B-Rep Shape 与渲染 Mesh 是两类不同数据。需要 Mesh 前先明确用途：

- Viewer 显示通常由 OCCT Presentation 自己管理；
- 自定义渲染、导出、碰撞预筛选或三角面分析需要显式 Triangulation/Mesh 数据。

示例：

```csharp
model.Triangulate(shape);
var mesh = model.GetShapeMesh(shape);
```

网格精度参数应根据模型尺度与用途设置。不要用极小 Deflection 作为默认值，否则大模型会产生不必要的三角形数量和内存开销。

## 2. 单 Face Mesh

Face 级 Mesh 读取适合：

- 局部渲染；
- Face 级分析；
- 拾取后的局部几何处理；
- Face 结果着色。

节点和三角形集合通过 Bulk Native ABI 传输，避免逐 Node/Triangle 跨 P/Invoke。

## 3. 合并 Shape Mesh

```csharp
OcctMesh mesh = model.GetShapeMesh(shape);
```

该接口把多个 Face 的网格合并为一个节点/三角形集合，适合：

- GPU 上传；
- 自定义渲染；
- 通用三角网格导出；
- 大模型快速几何预览。

普通合并 Mesh 本身不会直接说明某个 Triangle 来自哪个源 Face。

## 4. Mesh Provenance

需要保留 Face 来源时使用：

```csharp
var data = model.GetShapeMeshData(shape);
```

`OcctShapeMeshData` 包含：

- `Mesh`；
- `FaceRanges`；
- `FaceCount`；
- `NodeCount`；
- `TriangleCount`；
- `GetFaceRange()`；
- `TryGetFaceForNode()` / `GetFaceForNode()`；
- `TryGetFaceForTriangle()` / `GetFaceForTriangle()`。

每个 `OcctShapeMeshFaceRange` 保存一个源 Face 在合并 Mesh 中的连续区间：

```text
NodeStart
NodeCount
TriangleStart
TriangleCount
```

因此不需要给每一个 Triangle 单独附加 Face ID，额外来源数据规模主要与 Face 数量相关。

## 5. Triangle 拾取后反查 Face

如果自定义渲染器返回合并后的 Triangle 索引：

```csharp
if (data.TryGetFaceForTriangle(hitTriangleIndex, out var sourceFace))
{
    // sourceFace 可继续用于属性、分析或选择映射。
}
```

典型用途：

- BIM/CAD 属性映射；
- Face 级结果着色；
- 问题定位；
- 自定义 GPU Picking；
- 局部分析；
- 选择性导出。

## 6. Mesh 数据是快照

`OcctShapeMeshData` 返回 Managed 快照。后续重新 Triangulate、ClearTriangulation 或修改 Shape，不会反向修改已经返回的 Managed Mesh。

模型发生变化后需要重新生成 Mesh 数据。

## 7. 数据交换

Modeling API 支持：

```text
STEP
IGES
BREP
STL
```

并提供通用文件导入入口。

常见用法：

```csharp
var imported = model.ImportStep("input.step");
model.ExportStep(imported, "output.step");
model.ExportStl(imported, "output.stl");
```

具体方法签名以当前 `OcctModelingSession.Exchange` 公共 API 为准。

## 8. B-Rep 与 STL 的区别

STEP/IGES/BREP 主要用于保留 CAD 几何/拓扑信息；STL 是三角网格格式。

如果后续还要执行：

- Boolean；
- Face/Edge 查询；
- 精确尺寸；
- Topology Reference；
- Surface/Curve 分析；

优先保留 B-Rep/STEP，而不是提前转成 STL。

## 9. Viewer 与 Modeling 互操作

Headless Shape 可以显示到 Viewer：

```csharp
var displayed = engine.Display(model, shape, fit: true);
```

这里发生的是跨 Registry/Session 的受控复制/注册，而不是把 `OcctModelShape` 的裸 ID 当作 `OcctEngine` Object ID 使用。

## 10. 大模型建议

- 只做 B-Rep 算法时不要提前生成 Mesh；
- 只需渲染时使用 `GetShapeMesh()`；
- 需要 Face 来源时使用 `GetShapeMeshData()`；
- 避免反复对未变化 Shape 重新 Triangulate；
- 大数组读取使用 Bulk API；
- STEP/IGES 导入后先做 Bounds/Topology/Inspection 摘要，再决定是否进行昂贵分析；
- STL 不应作为需要精确拓扑语义的中间格式。

## 11. 所有权

Mesh Provenance 中返回的 Face 仍是当前 `OcctModelingSession` 的 `OcctModelShape`。不能跨 Session 使用这些 Face Handle。

文件导入后得到的新 Shape 同样属于执行导入的 Session。
