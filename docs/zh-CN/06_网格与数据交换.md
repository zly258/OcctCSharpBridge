# 06 网格与数据交换

## 网格

`GetShapeMeshData` 返回统一节点数组、Triangle Connectivity 和按 Face 划分的 provenance range。逐 Face Triangle Index 已转换到统一节点数组索引，便于上层严格校验或直接可视化 Bridge 返回的真实三角网格。

Meshing 参数包含 Linear/Angular Deflection、Minimum Size、Relative、Parallel、Internal Vertices 与 Surface Deflection Control。

## STEP

`ImportStep()` 保留普通 Shape 导入兼容路径。

需要真实装配语义时使用：

```csharp
OcctAssemblyDocument document = engine.ImportStepDocument("assembly.step");
```

装配快照保留：

- 稳定 XDE Assembly Item ID；
- Assembly / Instance / Part 类型和父子关系；
- Reference Name；
- Local / Global Occurrence Transform；
- Visibility；
- Surface RGBA / Transparency 与 Curve Color；
- 显式 Subshape Style。

Part 由 XDE 产品结构定义，不能按 Solid 数量推断。因此一个合法的多 Solid Part 仍是一个 Part。

几何未改变时，Name/Color/Transparency/Visibility 等非几何修改可以同步回原始 XDE Document，导出时继续保留原 Assembly/Instance 引用关系与未修改 Subshape Style。真正修改拓扑后才进入重建导出路径。

## IGES / BREP / STL

IGES、STEP 使用 OCCT Exchange Toolkit；BREP 直接持久化 OCCT 拓扑；STL 交换三角网格。运行时除 DLL 外还可能需要 OCCT Resource 目录。

这里的 XDE 是 STEP 数据交换内部实现，不是应用层 Document 架构。
