# 几何构建机制

## 1. 建模会话

脚本构建使用 `OcctModelingSession`。该对象是无界面的 OCCT 建模会话，负责持有命令生成的 `OcctModelShape`。构建协调器在整个文档构建期间复用同一个会话。

## 2. 首批真实命令

当前已实现：

- `BoxCommandBuilder`
- `CylinderCommandBuilder`

字段允许直接填写常量或参数表达式。Box 使用 `width`、`depth`、`height`；Cylinder 使用 `radius`、`height`。

## 3. 构建流程

1. 计算文档参数。
2. 按命令 `Order` 排序。
3. 从注册表取得 `ICommandShapeBuilder`。
4. 计算命令字段。
5. 调用 `OcctModelingSession` 创建 Shape。
6. 应用平移、旋转和缩放。
7. 将命令 ID 与 `OcctModelShape` 建立映射。
8. 汇总每个命令的错误与状态。

## 4. 视图显示

构建结果可以通过：

```csharp
var aisShape = engine.Display(coordinator.Session, modelShape, fit: true);
```

复制到 `OcctEngine` 的 AIS 交互环境。显示后的 `OcctShape` 属于 `OcctEngine`，建模结果仍属于 `OcctModelingSession`。

## 5. 生命周期

`ScriptBuildCoordinator` 实现 `IDisposable`。关闭文档时必须释放协调器，从而释放对应的原生建模会话。重新全量构建前调用 `session.Clear()`，避免旧 Shape 长期保留。
